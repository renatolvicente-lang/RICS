<h1>XAM<b>P</b>P</h1>

<h2>O que é o XAMPP</h2>

<p>O Xampp é um pacote de ferramentas mais conhecidos quando a assunto é desenvolvimento local de aplicações web.</p>
<img src="https://assets-blog.hostgator.com.br/wp-content/uploads/2025/09/image-98.webp" >
<p>Ele foi criado  para facilitar a vida de programadores e estudantes que precisam de um servidor mais compreto instalado no proprio computador, sem a necessiade de configurar manualmente cada serviço.</p>

<p>Com ele é possivel rodar projetos em <b>PHP, MySQL/MariaDB, Apache e Perl</b> de maneira rápida e prática, simulando as condições de um servidor real.</p>

<p>O nome <b>XAMPP</b> é, na verdade, um <b>acrônimo</b> que representa seu principais componentes.</p>

<ul>
<li><b>X</b> = Multiplataforma(Compativel com Windows, Linux e macOS);</li>
<li><b>A</b> = <b>Apache</b>, o servidor web mais utilizado no mundo;</li>
<li><b>M</b> = <b>Mariadb/MySQL</b>, banco de dados relacional para armazenar e gerenciar informações;</li>
<li><b>P</b> = <b>PHP</b>, linguagens de programação essencial para o desenvolvimento web dinâmico;</li>
<li><b>P</b> = <b>Perl</b>, linguagem versatil usada em automação e manipulação de dados.</li>
</ul>


<h2>Componentes Inclusos</h2>

<p>O <b>XAMPP</b> não é só Apache, PHP e MySQL/Mariadb. Ele tem uma série de outras ferramentas adicionais.</p>

<p>Um Exemplo é o <p>phpMyAdmin</p>, amplamente usado para gerenciar BDs de forma grafica, sem necessidade de comando SQL complexos.</p>

<p>Além dele, o pacote traz o <b>Mercury Mail Server</b>, ideal para testar o envio de e-mails em ambientes locais, o <B>FileZilla FTP Server</B>, que permite simular transferências de arquivos por FTP, e até Tomcat, util para aplicações em Java</p>
